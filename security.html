Privacy Policy

Last updated: August 2026

1. Data We Collect

MTH Bot operates primarily inside temporary process memory and utilizes a local layout file. We strictly store user Discord IDs and relevant server metadata required to manage daily payout loops, automated tracking milestones, and cash drop activity metrics.

2. How We Use Data

Stored data is strictly utilized to process active user balance modifications, target structural message counts, and pass validation requirements safely to the UnbelievaBoat API infrastructure.

3. Third-Party Sharing

We do not sell, trade, or distribute your information to outside entities. Relevant data identifiers are safely transmitted solely to UnbelievaBoat to adjust currency balances requested by server actions.

4. Data Retention and Deletion

Tracking profiles are safely deleted from our active state instantly when your Server Boost profile expires or is stripped from the network architecture. Users can request total removal by contacting server operators directly.
